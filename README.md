# HEALA-Handshake
HEALA is a simulation of an emergency referral "handshake" for Delta State, Nigeria (USPF Changemaker Challenge, health sector). A health worker dials a USSD line, three matched hospitals get an SMS, the first ACCEPT locks the referral, then arrival and outcome are recorded and shown on a live dashboard. Deadline: Sunday 15 Nov 2026, 11:59 p.m. WAT
